# Portafolio de evidencias — Programación Web I

Portafolio de evidencias de la asignatura *Programación Web I* (Ingeniería en
Tecnologías de la Información, Universidad Politécnica de San Luis Potosí,
Primavera 2025).

El repositorio reúne dos trabajos prácticos:

## Contenido

| Ruta | Descripción |
|------|-------------|
| `index.html` | Portafolio: presentación del alumno, misión/visión de la carrera, objetivo y contenido de la materia |
| `Index/` | Práctica "El Sistema Solar": tabla interactiva de planetas con imágenes y un iframe |

## Práctica: El Sistema Solar

`Index/index.html` muestra una tabla con los planetas (Mercurio, Venus, Tierra,
Marte) donde cada imagen reacciona al pasar el cursor y se abre contenido
relacionado en un iframe. Estilos con degradado espacial y tipografía dorada.

## Estructura

```

Index/
  index.html            Práctica El Sistema Solar
  mercurio.jpg venus.jpg tierra.jpg marte.jpg
```

## Ejecutar

Sitio estático: abre `index.html` en el navegador.
